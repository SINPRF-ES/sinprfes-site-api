# ASSEMBLEIA - Log Oficial de Ocorrências

Este documento registra todas as ocorrências, falhas e melhorias identificadas durante o uso recorrente do sistema.

## 1. Critério de Mudança
- **CANON:** Não alterar regras de voto, quórum, elegibilidade ou snapshot sem decisão formal da diretoria/TI.
- **Hotfixes:** Permitidos apenas para bugs críticos, segurança e melhorias de UX que não alterem a lógica estatutária.
- **Mensagens:** Melhorias em mensagens de erro e logs são encorajadas para aumentar a robustez.
