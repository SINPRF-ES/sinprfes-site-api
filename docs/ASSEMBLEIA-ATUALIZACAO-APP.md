# ASSEMBLEIA - Procedimento de Atualização do App

Este documento define a política de versionamento e atualização do aplicativo mobile para os filiados.

## 1. Política de Versionamento
- O app deve manter compatibilidade com a última versão estável do backend.
- Atualizações críticas de segurança ou regras de voto exigem atualização obrigatória do app.

## 2. Quando Atualizar
- **Melhorias de UX:** Podem ser feitas a qualquer momento, preferencialmente entre assembleias.
- **Correções de Bug:** Imediatamente após a validação em ambiente de homologação.
- **Novas Funcionalidades:** Conforme cronograma de desenvolvimento, respeitando o congelamento pré-evento (72h antes de uma assembleia).

## 3. Quando NÃO Atualizar
- **72h antes de uma assembleia:** Congelamento total de código (Code Freeze).
- **Durante o evento:** Jamais realizar deploy de novas versões do app ou backend durante uma assembleia em curso.

## 4. Comunicação aos Filiados
- Notificações Push devem ser enviadas informando sobre atualizações importantes.
- O link para as lojas (Google Play / App Store) deve ser reforçado nos editais de convocação.
