Área do Filiado

Acesse a Área do Filiado para consultar e atualizar seus dados cadastrais, além de acessar conteúdos exclusivos.

Digite apenas os 11 números do seu CPF.

Abra o aplicativo autenticador (Google Authenticator ou similar) e informe o código temporário exibido para o SINPRF-ES.

Esqueci minha senha / Primeiro acesso

Se for seu primeiro acesso, ou se você esqueceu sua senha, utilize esta opção. Você receberá um link no e-mail cadastrado para criar uma nova senha.

Digite apenas os 11 números do seu CPF.

O sistema informará para qual e-mail o link foi enviado. Caso o e-mail esteja incorreto ou você não tenha mais acesso a ele, favor entrar em contato com a secretaria, pela página Contato.
